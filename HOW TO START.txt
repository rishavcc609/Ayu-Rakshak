AYU RAKSHAK — WINDOWS PORTABLE DEMO

1. Extract the ZIP file.
2. Open the extracted AYU-RAKSHAK-Portable folder.
3. Double-click Start AYU RAKSHAK.bat.
4. The login page will open automatically in your default browser.

Requirements

- Python 3 installed and available as the "python" command
- Ports 4174 and 8000 must be available
